# 像素风格基线

参考项目：`/Users/meo/Desktop/momo 历险记`

## 视觉判断

当前项目不直接复制《星露谷物语》或 momo 的私人素材，而是复用已经验证过的风格规律：

- 竖屏移动端，宽度按 390px 设计。
- 背景使用粉紫月光森林、深蓝夜色、暖橙点缀。
- UI 使用黑色硬边框、无圆角、无抗锯齿感。
- 主操作按钮用暖橙色，普通面板用深蓝紫。
- 中文文本使用 Fusion Pixel Font，避免回退到系统中文字体后变糊。
- 背景必须先服务 UI 可读性：顶部 HUD 和底部面板附近不能塞高对比细节。

## 统一色板

- `#1a1a2e` 夜色面板
- `#16213e` 深蓝阴影
- `#2a2a4e` muted 面板
- `#e8dff5` 月光文字
- `#ffd4a3` 暖桃高光
- `#ffb5c0` 粉色高光
- `#ff8c42` 橙色主按钮
- `#b4a5d5` 薰衣草辅助文字
- `#fef9ef` 奶油白
- `#000000` 像素硬边框

## 素材原则

- 优先 `image2/gpt-image-2` 生成一整套统一素材。
- 开源素材只在“同一套、授权清楚、覆盖 UI/角色/怪物/场景关键件”时引入。
- 不混用多个作者的零散像素包当主视觉。
- 透明角色素材必须单独裁切、命名清楚、记录来源。
- 背景、角色、UI、图标必须共享同一色板和像素密度。
