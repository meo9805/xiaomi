# 小咪变成人啦！大冒险

项目起点：一个面向 iOS 竖屏移动端的 2D 像素放置 RPG。正式游戏名定为“小咪变成人啦！大冒险”；“月森营地”保留为游戏内第一章/营地地点名，文件夹名“星露谷”只是项目参考语境。

当前不是要复刻《星露谷物语》的系统，而是借鉴它“温暖、清晰、舒服、像素感强”的 UI 和视觉气质。玩法先控制在一个人能完成的范围内：自动打怪、经验升级、掉落、装备/属性强化、任务和离线收益。

## 当前倾向

- 引擎：Godot 4
- 平台：iOS 竖屏优先，后续可兼顾 Web/桌面预览
- 风格：cozy pixel art、温暖 RPG UI、森林/营地/小冒险氛围
- 类型：放置 RPG，而不是完整农场模拟或大型开放世界 RPG
- 素材：优先用 Codex 内置 image/image2 生成统一素材；开源素材只在成套且授权清楚时使用

## 推荐 MVP

第一版只做一个很小的闭环：

1. 一个竖屏主界面：上半部分像素森林/营地场景，下半部分 RPG 面板 UI。
2. 一个主角自动攻击小怪。
3. 怪物掉落金币/材料/经验。
4. 角色升级后提升攻击、生命或收益效率。
5. 底部页签：战斗、战力、背包、副本、伙伴。
6. 离线一段时间回来能领取基础收益。

## 协作方式

用户负责方向、审美和取舍；Codex 负责调研、拆范围、搭项目、写代码、接素材、验证页面/构建，并把复杂技术事项包装成可执行的小步骤。

下一步建议：先用 Godot 4 做一个极小可玩的竖屏原型，而不是继续扩展需求清单。

## 本地运行

用 Godot 编辑器打开本文件夹即可：

```bash
godot -e --path /Users/meo/Desktop/星露谷
```

命令行快速跑一遍：

```bash
godot --path /Users/meo/Desktop/星露谷 --resolution 390x844
```

无界面校验：

```bash
godot --headless --path /Users/meo/Desktop/星露谷 --quit-after 5
```
